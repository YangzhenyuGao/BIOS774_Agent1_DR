Agent 1: empirical dimensionality reduction

BIOS 774 · Local reproducible statistical agent · Scientific wording is a draft for user review.

Problem and contribution

A useful dimensionality-reduction workflow should explain why a method advances on the dataset at hand. This agent inspects numerical data, chooses explicit preprocessing, attempts all supported methods on a common pilot, and uses measured quality, stability, failures, and runtime to select a small final candidate set. It then tunes only that shortlist and produces auditable reports.

Architecture and tools

A Python src package exposes inspect → pilot → select → tune → final → report → validate through one CLI and run-all. Typed configuration, atomic JSON artifacts, content checksums and subprocess isolation make stages resumable. SLURM supplies CPU execution; Python scientific packages implement numerical tools. Jinja2 and WeasyPrint generate PDFs, checked with pypdf. No multi-agent framework, web service or database is required.

All ten methods are real implementations: PCA, Kernel PCA, MDS, Isomap, LLE, Laplacian Eigenmaps, Diffusion Maps, Bayesian GPLVM, t-SNE and UMAP. Scikit-learn supplies seven, pydiffmap supplies diffusion maps, GPyTorch optimizes Bayesian GPLVM, and umap-learn supplies UMAP. The GPLVM loss and changes from PCA initialization are recorded.

Dataset-aware planning and decision logic

PBMC count data undergo fixed cell QC, cohort-specific gene filtering, library normalization, log transformation, variable-gene selection, and scaling. PathMNIST uses consistently scaled RGB pixels. Cohorts are stratified where annotations exist, while all fitting and selection exclude labels. A cohort-fitted PCA representation supplies identical numerical input to every method.

Quality combines trustworthiness (weight 0.45), nearest-neighbor recall (0.45), and seed stability (0.10). Methods meeting 90% of the best quality or on the quality–runtime Pareto frontier are eligible; candidates are ranked by quality, runtime, then name. Successful PCA is retained as the baseline, with at most four finalists. Severe connectivity or singularity warnings exclude a method. All original warnings and failures remain visible.

Stochastic methods have repeated seeds; deterministic stability is defined as one. Shortlist refinement uses the same criteria. Silhouette is secondary. These are descriptive in-cohort analyses; there is no held-out inference claim.

Assessment and reproducibility

Strengths and limits

The same public interface adapts to sparse count data and dense images, with transparent common-cohort comparisons and quantitative candidate selection. Traceable artifacts preserve failed attempts and numerical warnings instead of presenting only attractive embeddings. Runtime-aware cohort planning makes expensive methods feasible under a declared budget.

Results depend on representation, metric weights, neighborhood scale and random seeds. Local metrics do not fully measure global structure. Deterministic methods receive a defined stability value; this is not proof of robustness to resampling. GPLVM uses a fixed optimization budget and may need longer training. Disconnected graph warnings conservatively exclude methods. Cold-start imports affect runtime, and cubic planning bounds are conservative assumptions rather than measured scaling laws.

PathMNIST pixel distances need not reflect all histological semantics. PBMC processed labels originate from prior clustering and do not provide independent biological ground truth. No causal, clinical or generalization conclusion follows from the embeddings. Neither source is sent to an external model in deterministic mode.

Reproduction and audit

Run scripts/01_setup_environment.sh for the exact agent environment, then scripts/03_smoke_test.sh inside a SLURM allocation. Stage scripts in scripts/slurm accept a dataset config. Run python -m agent1_dr run-all --config config/pbmc3k.yaml --resume and the analogous PathMNIST command on compute nodes. Finally run project-report and validate --all-reports. The lock files, configuration/code hashes, source checksums, cohort IDs, seeds, and job manifests specify the evidence chain.

Three PDFs are generated from validated artifacts. The default mode is deterministic templating, not an LLM-written report. An optional OpenAI interface can organize exact evidence sentences and rejects unsupported claims; live API operation requires credentials. Tests exercise the actual methods, GPLVM optimization, failure isolation, metric behavior, selection and a fresh end-to-end synthetic run.
